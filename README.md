# English Conference Prep (IITI 2026)

Материалы для подготовки к англоязычной конференции по статье:

**Effectiveness of Machine Learning Methods and Survival Analysis in Assessing Mortality Risk in Patients with Acute Coronary Syndrome at Various Observation Horizons**

🔗 Репозиторий: https://github.com/Barracuda556/English-Conference-Prep

## Что здесь есть

| Файл | Описание |
|------|----------|
| `План_уроков_на_месяц.md` | План занятий на 30 дней (структура и ключевые темы) |
| `decode_docx.sh` | Скрипт для сборки оригинальных .docx из частей |
| `docx_base64/` | Служебные файлы (base64-части документов) |

## Оригинальные файлы Word (рекомендуется)

Полные материалы в формате `.docx` доступны для скачивания **в артефактах проекта Grok**:

1. **Полный_словарик_для_конференции.docx** — словарик терминов, фраз презентации и Q&A  
2. **План_уроков_на_месяц.docx** — детальный план на 30 дней  
3. **Методичка_к_плану_уроков.docx** — полная методичка с правилами, примерами, упражнениями и готовыми ответами  

> Эти три файла — основной комплект для подготовки. Скачайте их из чата/проекта Grok.

## Как пользоваться

1. Скачайте три `.docx` из артефактов Grok.  
2. Читайте **План** по дням.  
3. Параллельно открывайте **Методичку** — там полное раскрытие каждой темы.  
4. Учите слова из **Словарика**.  

Ежедневно 45–70 минут, говорите **вслух** и записывайте себя.

Удачи на конференции!
