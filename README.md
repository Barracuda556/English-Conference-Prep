# English Conference Prep (IITI 2026)

Материалы для подготовки к англоязычной конференции по статье:

**Effectiveness of Machine Learning Methods and Survival Analysis in Assessing Mortality Risk in Patients with Acute Coronary Syndrome at Various Observation Horizons**

## Файлы

| Файл | Описание |
|------|----------|
| `Полный_словарик_для_конференции.md` | Полный словарик: термины статьи, фразы презентации, Q&A, грамматические конструкции |
| `План_уроков_на_месяц.md` | План занятий на 30 дней (4 недели) |
| `Методичка_к_плану_уроков.md` | Подробная методичка: правила, примеры, упражнения, готовые пересказы и ответы на вопросы |

Оригинальные файлы Word (`.docx`) лежат в папке проекта Grok / артефактах. Здесь выложены markdown-версии для удобного просмотра на GitHub.

## Как пользоваться

1. Читайте **План_уроков_на_месяц** — расписание по дням.
2. Параллельно открывайте **Методичку** — там полное раскрытие каждой темы.
3. Учите слова из **Словарика**.

Ежедневно 45–70 минут, говорите вслух и записывайте себя.

Удачи на конференции!
